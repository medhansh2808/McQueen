## A. FIXED — WAN loop down: dead cloudflared tunnel + stale broker URL (F8, not port-forward)

| Item | Detail |
|------|--------|
| Symptom | Full WAN loop refused to come up: sender/receiver logs absent, signaling handshake failed, stale URL file pointed at a dead host |
| What was checked and RULED OUT | RTX public IP unchanged (`14.139.108.62`); RTX ufw INACTIVE; iptables INPUT policy ACCEPT; LAN probe to a `0.0.0.0:5955` listener 10/10 (avg 3.36 ms) — so local firewall/port state on the RTX was never the problem. The `5955` listener is only used for the RTT probe tool anyway: **the realtime pipeline does not listen on any fixed port** |
| Actual mechanism discovered | The receiver binds an **ephemeral port (`0.0.0.0:0`)**, exchanges its public address via STUN, and the peer (Jetson) sends directly to the **punched** public endpoint. Campus NAT is endpoint-independent → the punch succeeds with NO forward configured. Verified live: receiver public `14.139.108.62:49995` (later `:41820`, `:53591`), Jetson public `152.59.109.96:59856`; media/control then flowed peer-to-peer over UDP |
| True root cause | The **cloudflared tunnel on the RTX was dead** (log: `Tunnel server stopped`, stale since a prior day) and the saved URL file (`cloudflared.url`) pointed at the dead hostname `unfortunately-wrestling-kim-traveller.trycloudflare.com`. Without a live broker, the STUN punch could not be arranged → nothing started → loop down. This is the F8-class failure (stale broker URL) from prior sessions |
| Fix | Started fresh `cloudflared` → new URL `https://carlo-booth-austin-pics.trycloudflare.com`; refreshed URL file; signaling verified from the Jetson (`{"ok": true ...}`) |
| Verification | Full WAN loop re-measured: `CTRL_RX n=960` on the Jetson, `LAT_p50=276.5 ms / LAT_p95=486.7 ms` @300 kbps — reproduces the 2026-08-14 result (~287 ms @150 kbps). Bitrate A/B completed after the fix (see evidence REPORT) |
| Residual | `cloudflared` remains ONLY for the startup broker rendezvous; the media/control path never touches it. A brokerless re-punch design (drop cloudflared entirely) is a recorded future item, not yet implemented |
| Status | **FIXED** (verified live) |
